# 本地修订说明

本包不是灵枢官方发布。核心来源为同一仓库的灵枢 2.68 源码；桥接版本为本地 v0.2.1。仓库链接仅标记上游来源；不要用插件商店的上游更新覆盖此修订版。

v0.2.1 变更：
- 对话前召回只取用户本轮消息（`event.get_message_str()`），不再把宿主 system prompt / 人格设定混入检索；跳过 `lingshu` 命令消息。
- 新增可选对话后写回（`on_llm_response`，默认关闭）：只写用户消息，不写助手输出；敏感词（密码、密钥、token、银行卡号等）拦截；按 `(平台实例, 群, 用户)` 节流；最小长度限制；后台任务不阻塞回复，停用时取消。
- 人格隔离：只读取既有 `persona.json` 的状态，绝不调用 `init` / `startup`，不创建、不注入、不改写宿主人格。
- 安全：沿用精确 owners 鉴权、跨平台实例隔离、同群授权召回、隐私查询门控（`recall --asker/--target`，未授权返回 4）。

原 v0.2.0 改动：重写 AstrBot 配置接收和命令入口；捆绑核心；使用 AstrBot 数据目录；限定平台实例身份；精确 owners 判定；传递 CLI 二次鉴权身份；修正记忆去重/冲突的用户归属；修正跨平台群可见性；普通召回执行同群分享授权；群内不召回个人跨群/私聊记忆；“问”按问题过滤目标；可选带字符预算的 LLM 召回；后台进程、并发限制、超时清理和输入限制。

仅修改核心 memory.py 的 remember、_channel_visible、recall。跨用户做梦、自动人格演化、自动情绪更新仍未完成隔离改造，不开放聊天中的“做梦”。独立本地管理面板仍是全库管理入口；不要将面板端口直接公开。

新数据目录不会自动读取 ~/.brain-memory；旧库可能已发生跨人合并，请备份、审阅并逐条迁移。此包是供测试部署的候选版本；尚未完成真实 AstrBot 端到端、Linux/macOS/ARM/Docker 实机验证。受限托管环境如果不允许子进程或持久存储，不能使用此方案。
