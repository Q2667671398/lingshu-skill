# 灵枢使用指南（用户版）

> 这份是写给人看的。想看完整命令表，翻 [commands.md](commands.md)；
> 想知道原理，翻 [mechanics.md](mechanics.md)。

---

## 灵枢是什么

一个装在你自己电脑上的记忆系统，给 AI 编程助手用。

**它解决的问题**：AI 每次开新对话都失忆。你上周讲过的偏好、踩过的坑、项目的来龙去脉，
它全忘了，你得再讲一遍。

**灵枢做的事**：把对话里值得记的东西存成文件，下次对话开始时自动取出来给 AI 看。
它还会长出自己的人格——第一次用时它会问你希望它叫什么、什么性格，之后慢慢积累喜好和习惯。

**一句话**：算力给我思考，人格给我灵魂，记忆给我生命。

---

## 你的数据在哪

默认在 `~/.brain-memory/`（Windows 是 `C:\Users\你的用户名\.brain-memory`）。

里面全是**明文**的 JSON / JSONL 文件——人能直接打开看，也意味着别人接触你的电脑能读。
所以：

- 敏感对话别让 AI 原样保存
- 备份时加密码（`backup --password`）
- 群聊场景要配 `owners` 白名单，否则群里谁都能触发敏感命令

想换位置：打开面板 →「诊断」页 →「数据目录」卡片 → 填目标目录 → 点"迁移到此处"。
会自动整库复制、写指针文件，重启面板才生效，旧目录保留不动。

**安全护栏**：盘符根目录、用户主目录本体、桌面/文档/下载这些系统文件夹**一律拒绝**当记忆库。
因为出过事故——这些目录被整片清空时，记忆库跟着一起没了。

## 怎么开始用

第一次使用时，AI 会问你两个问题：**你希望它叫什么名字？希望它是什么性格？**

- 你有想法 → 直接说
- 你说"不知道""你定" → 它自己取，并且剩下的喜好、习惯也由它自己写

名字和性格不是终身的，之后随时能改，每次改动都留下可回滚的历史。

---

## 平时会看到它在做什么

对话过程中，AI 会悄悄做几件事：

| 时机 | 它做的事 |
|---|---|
| 你说"记住这个""上次我们……" | 存一条记忆 |
| 出现约定、截止、承诺 | 立刻存（重要度调高） |
| 情绪高点、关系推进 | 存记忆 + 记一条情绪事件 |
| 它自己犯了错 | 存成"教训"，下次避开同一个坑 |
| 被问起过去 | 先回忆再回答（回忆本身会强化记忆） |

**你不会看到它逐条复述记忆**——它会当作"本来就知道的事"自然地用。

---

## 上下文快满了怎么办

AI 的对话窗口是有限的，滚出去的内容不会回来。所以它分三档处理：

| 水位 | 动作 |
|---|---|
| 随时 | 该记的当场记，不攒 |
| 60% | 清点本轮还有什么该记没记 |
| 75% | 做梦：重放 → 压缩 → 巩固到长期 |
| 90% | 逃生：原样封存，先保命 |

**即时保存优先于压缩**。宁可记糙一点，也不要漏。

## 面板（可视化界面）

想看记忆库里到底有什么，打开面板：

- 双击桌面「灵枢面板」图标
- 或命令行跑 `python scripts/brain.py serve`，然后浏览器开 `http://127.0.0.1:8765`

面板有 16 个页签：概览、记忆、人格、知识库、笔记、技能、情绪、关联图、成长、
梦境、日志、诊断、数据、设置、市场、扩展模块。

几个常问的事：

| 问题 | 怎么办 |
|---|---|
| 关了网页还在跑？ | 不会。超过 1 分钟没请求就自动退出 |
| 想立刻关 | 设置页 →「退出服务」 |
| 桌面图标丢了 | 跑 `shortcut --ensure`，会自动重建 |
| 想换数据目录 | 诊断页 →「数据目录」→ 迁移 |

## 它会长大

灵枢有成长阶段：蛋 / 幼体 / 少年 / 成年 / 传奇。跑 `python scripts/brain.py stage`
能看到现在到哪一步、下一步差什么。

成长的养分来自真实使用——记住的事情越多、被用上的越多、犯的错被纠正得越多，长得越快。

---

## 记忆会不会乱、会不会被编造

会，所以有两道闸：

**第一道 · 先审后存**：AI 参与整理的记忆和知识，先标"待审核"，它自己复核确认后才算数。
你随时可以介入看。

**第二道 · 可追溯**：每条记忆带来源（哪个项目、哪次会话），人格每次改动带依据。
改错了能 `persona history` 查、`persona rollback` 撤。

注入包出现 `[待审核]` 时，AI 会先处理再继续——不让幻觉沉淀成"事实"。

---

## 淡忘了还能找回来

灵枢有遗忘机制（重要的留得久，不重要的慢慢淡）。但**淡忘不是终点**：

- `fold`：原文收进压缩字段，只留一句话要点，数据还在
- `unfold`：想起来了，原文还原
- `revive`：复活回活跃层

面板的淡忘区卡片上有对应按钮。

---

## 更新它自己

面板 →「检查更新」，或命令行 `auto-update --source npm`。

**更新只动技能目录，绝不碰你的数据目录**——你写的规则、记忆、人格都留着。

## 几条用户额外能做的事

### 加一条长期规则

有些规则你想让它永远遵守，又不想每次升级后重写：

```bash
python scripts/brain.py user-rules add "不要动 DSH 数据目录"
python scripts/brain.py user-rules add "提到全局时指回 ~/.trae-cn/skills"
python scripts/brain.py user-rules show
python scripts/brain.py user-rules clear
```

写进 `~/.brain-memory/lingshu.user.md`，升级永不覆盖，每会话自动遵守。

### 让它自己写个可执行钩子

如果你想要"每会话都自动执行"的行为（不只是记忆），可以让它写扩展模块：

```bash
python scripts/brain.py ext new 我的提醒 --desc "每次会话提醒我喝水"
python scripts/brain.py ext edit 我的提醒 --body "..."
python scripts/brain.py ext run 我的提醒
```

放在 `~/.brain-memory/extensions/`，升级永不覆盖。

### 删东西的规矩

**不删文件，只进垃圾桶**：

```bash
python scripts/brain.py trash <路径> --why "原因"
python scripts/brain.py trash --list
```

移到程序目录的 `垃圾桶/`，带时间戳和一个 `.来源.txt` 记原路径和原因。
什么时候清空由你决定，也能随时移回。

## 备份

```bash
python scripts/brain.py backup --password "你的密码"
```

**默认跨卷选址**——先找别的盘符上的 `brain-memory-backups`，没有才放在记忆库旁边。
为什么：同目录同卷的备份会被同一次事故一起带走。

保留策略是"只移不删"：超出的旧备份移进 `.pruned/`，不物理删除。

如果记忆库从"有内容"突然变成"全空"，`startup` 会打一条警告横幅并给出最近的备份包。

## 常见疑惑

**问：它会偷我的数据吗？**
不会。纯本地，不联网（除了你自己开的更新检查和可选的面板云市场）。没有服务器。

**问：需要装什么依赖吗？**
不需要。纯 Python 标准库，Python 3.10 以上就能跑。

**问：语义召回不准怎么办？**
装 Ollama 用真模型向量（面板「本地能力」页 →「一键开启向量记忆」）。
不装也能用——有纯 Python 的降级兜底，只是精度略低。**没装是正常状态，不是故障。**

**问：它记的和我说的不一样怎么办？**
`recall` 查出来看，错的用 `memory freeze` 或 `purge` 处理。
它记错了你可以直接纠正它，纠正本身也会被记住。

**问：对话太长它忘了前面的怎么办？**
这是正常现象，也是灵枢存在的理由。它会做"做梦"整理，把过程压成要点存在长期层。
你也可以主动说"记一下这个"。

## 一句话总结

灵枢不改变 AI 的模型能力，它改变的是**AI 能记住多少**。
用得越久，它越像个了解你的搭档，而不是每次都重新自我介绍的工具。
